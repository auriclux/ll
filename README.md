# Loose Leaves
Snow Globe of the Brain · Mind Confetti

A vanity project: pieces from one mind, translated by AI, published so a link can travel by text.

- `barrel/` — the canon. One markdown file per piece, metadata header attached.
- `data/` — sections and pieces as data. Section labels live here; rename them freely, no address changes.
- Pages are static renderings of the barrel, rebuilt per package. Piece addresses are slug-only
  (`/ll/<slug>`) so re-shelving can never break a texted link.
